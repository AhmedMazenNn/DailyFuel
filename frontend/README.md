# DailyFuel frontend

React + TypeScript + Vite starter. Product screens have not yet been integrated.

```bash
npm ci
npm run dev
```

Validation: `npm run lint` and `npm run build`.

The complete original design is preserved locally at `../design-reference/frontend/` and excluded from Git. Port components in scoped feature PRs into `dev`, replacing mock behavior with the API as each feature is implemented. Do not copy its entire source tree or conflicting package manifests into this application.

See the [root README](../README.md), [PRD](../docs/prd.md), and [ERD](../docs/erd.md).
