No Django project or API exists yet. `requirements.txt` preserves the supplied dependency snapshot, renamed from `rrequirements.txt`. Validate supported dependencies in `feature/backend-foundation` before treating it as a reproducible setup.

That feature will add settings, Django REST Framework, PostgreSQL configuration, environment examples, and startup instructions. Do not commit virtual environments, databases, credentials, or private media.
